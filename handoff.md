# Prompt handoff inglese

````
Before we end this session, write a `handoff.md` file that captures:
- the goal we're working toward
- current state of the code
- files you're actively editing
- everything you're tried that failed
- the next step you'd take
````

# Prompt handoff italinao
  
````
Prima di concludere questa sessione, crea un file `handoff.md` che riepiloghi:
- l'obiettivo che stiamo perseguendo
- lo stato attuale del codice
- i file che stai modificando attivamente
- tutti i tentativi falliti
- il prossimo passo da compiere
````

# Prompt resume handoff inglese

````
Read `handoff.md` and pick up from exactly where it leaf off.
````

# Prompt resume handoff italiano

````
Leggi `handoff.md` e riprendi esattamente da dove ti eri interrotto.
````
